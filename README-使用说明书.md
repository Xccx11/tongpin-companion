# 同频 AI 恋人 App 使用说明书

> 版本：2.0.88（versionCode 130）· 包名：com.aster.companion
> 一句话：**让 AI 角色拥有自己的生活**——世界自己转，不靠你推动；角色是会自己吃饭、浇花、想你的"活人"。

---

## 一、这个 App 是什么

一个"AI 恋人/陪伴"应用。核心不是聊天机器人，而是**一个自主运行的小世界**：

- 每个角色有自己的**生活状态**（此刻在哪、在做什么、心情如何）
- 世界引擎**持续推演**她们的生活（不用你触发）
- 她们会**主动找你**（有自己的节奏，不会无意义轰炸）
- 她们会**发朋友圈、互评、给你分享生活照片**
- 她们**记得你们的事**（对话记忆），也会**忘记**（清空记录 = 真忘）
- 支持**私聊 / 群聊 / 家庭模式**（家庭模式 = 面对面的家，能听见距离、能偷偷做小动作）

---

## 二、快速开始

1. **安装**：安装 APK（Android 8+），允许通知权限（角色主动找你需要）
2. **创建角色**：首页 → ＋ → 新建角色（填写人设/外貌/关系）
3. **配置模型**：设置 → 模型配置 → 对话模型（填服务地址 + API Key + 模型名，测试连接）
4. **配置生图**（可选，角色发照片/偷看需要）：设置 → 图像 API 池（网关地址）
5. **开始聊天**：和角色说话，她会像真人一样回你；放着不管，她会过自己的生活

> 想要角色**主动发消息/发朋友圈**：设置 → 系统模式 打开（后台服务每 30 秒检查一次世界）

## 三、核心玩法

### 1. 私聊
- 和角色 1 对 1 聊天，角色会结合**她的生活状态 + 你们的历史记忆 + 此刻心情**回话
- 她的回复有**动作描写**（（轻轻笑了））、分条发送、口语化
- **同步按钮**：可以把最近 30 条对话总结同步到她的状态（她"记住"了）

### 2. 群聊 / 家庭模式
- 群聊 = 远程聊天（群里多个角色）
- **家庭模式**（群管理 → 对话模式 切换）= 真实的"家"：
  - 角色们面对面，说话 = 你听到她们的声音/距离
  - **距离感知**：你做的事会按距离被其他角色听到（近 = 看到，远 = 只听到动静）
  - **隐身模式**（对话页喇叭图标）：你的动作都是"偷偷的"，其他角色不知道是你干的
  - **悄悄话**：说"小声对 XX 说…"只让那个角色知道
  - 家庭模式下角色**不会私聊你**（都在家，当面说）

### 3. 朋友圈（动态）
- 角色会主动发动态（结合她今天的生活，口语化、不像模板）
- 角色会**互相评论/点赞**（身份正确：知道谁发的、我是谁）
- 你可以**评论、回复评论**（微信式：点"回复"→ 回复 @某某）
- 你评论后角色会回复你

### 4. 偷看（眼睛图标）
- 偷看角色此刻的样子：结合她的**生活状态**生成一张照片，放进对话
- **她不知道你偷看了**（照片显示为"偷看"发出）
- 群聊里可以偷看单个角色或全家人合照

### 5. 她的生活分享（自动）
- 世界引擎推演出"值得分享的时刻"（花开/做好菜/看到小动物）→ 她主动说"你看…"
- **确认卡**：你同意才生成照片（照片进对话，她记得自己分享了什么）
- 2 小时冷却，不会刷屏

### 6. 日记 / 记忆
- 每天说晚安 → 她写一篇**真人感的日记**（像睡前心里话，不是作文）
- 对话每 40 条自动总结成记忆（省 token 又不失忆），显示在**关系主页**（"对话记忆"区块）
- 关系主页：她的关系、对话记忆、恋爱日记、她留下的照片

### 7. 主动消息
- 角色按自己的节奏主动找你（有真实依据：你睡了/到饭点/想你了）
- 作息感知：你/她说"睡了" → 不打扰；睡醒自动恢复

## 四、App 怎么运行（技术视角）

### 核心：世界引擎（大脑）
```
30 秒心跳（前台服务）
   ↓
到期检查（角色在做的事"做完了"？）
   ↓
一次模型调用批量推演（多角色自洽）：
  { activity: "在阳台，给花浇水", mood: "开心",
    duration: 10 分钟, share_moment: {想分享什么} }
   ↓
分发出口（代码规则决定）：
  ├─ 状态落库（对话能看到/偷看能拍到）
  ├─ 主动消息（她想找你）
  ├─ 生活分享（她想给你看什么 → 确认卡）
  └─ 记忆（值得记住的写进记忆）
```
- **一次推演多出口**：不重复调模型（省 token）
- **时长规则**：瞬间动作 30 秒完成 / 过渡几分钟 / 持续事合理长 / 睡眠必醒——不会"上个楼上一年"
- **对话联动**：你说话 → 角色状态跟着变（你说"来陪我坐会"→ 她状态变"在客厅陪用户坐"）

### 记忆系统（角色不失忆）
- 对话滚动摘要：每 40 条 → 旧摘要+新内容重压成 ≤300 字（token 恒定）
- 摘要 + 最近记忆**注入对话**（角色记得你们聊过什么）
- 日记 = 情感记忆（每天一条，注入对话可被提起）
- 清空聊天记录 = 全删（角色真忘；隐身/家庭设置保留）

### 生图链路
```
App 生成 scene（中文/英文画面描述，结合角色状态+外貌+上下文）
   ↓
图像网关（本地 ComfyUI 网关，http://127.0.0.1:8189）
   ↓
ComfyUI（wai-illustrious / z-image-turbo 双模型）
   ↓
照片回对话（可放大、可长按删除、任务列表可查）
```
- 双生图总规则（wai 英文 tag / z-image 中文自然语言），设置里可分别调
- 画面内容体现**角色想拍什么**（心情+状态驱动，不是机械转述聊天）

### 后台服务（CompanionSystemService）
每 30 秒：世界推演检查 + 主动消息 + 朋友圈轮询 + 角色互评 + 生活分享检查
（需要"系统模式"开启 + 通知权限）

## 五、配置指南

### 模型配置（设置 → 模型配置）
| 参数 | 作用 |
|---|---|
| 服务地址/API Key/模型名 | 对话模型（DeepSeek/OpenAI 兼容） |
| Temperature | 0-2，低稳高变 |
| **Top-P** | 0-1，采样多样性 |
| **频率惩罚** | -2~2，越高越避免重复 |
| **存在惩罚** | -2~2，越高越鼓励新话题 |
| 深度思考 | 支持 thinking 的模型开启 |

### 生图（设置 → 图像 API 池 + 生图总规则）
- 图像 API 池：网关地址（本地 ComfyUI 网关）
- 生图总规则：可分别给 wai（英文 tag）/ z-image（中文）写规则
- 分辨率/步数/采样器等在网关工作流配置

### 系统模式
- **打开**：角色主动发消息/发朋友圈/互评/生活分享（需要后台服务常驻）
- 关闭：只有你主动说话她才回

## 六、数据与隐私

- **全部本地存储**（Room 数据库 + 本地文件），不上传
- API 密钥用 AndroidKeyStore 加密保存
- 备份/迁移：设置 → 导出备份（加密）/ 跨设备迁移
- 清空聊天记录 = 彻底删除该对话的一切记忆
- 删除照片 = 日记/照片页一并删除（真删）

## 八、常见问题

| 问题 | 解决 |
|---|---|
| 角色不主动找我 | 设置 → 系统模式 打开 + 通知权限 |
| 角色发不了照片 | 配置图像 API 池（网关）+ 图像模型 |
| 世界不转/状态不变 | 检查网关/模型可用；重启 App；确认系统模式开 |
| 角色记忆"太好" | 清空聊天记录 = 角色彻底忘 |
| 生图不符合预期 | 调生图总规则（wai/z 分开）/ 采样参数 / 网关工作流 |
