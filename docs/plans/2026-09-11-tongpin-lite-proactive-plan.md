# 同频 Lite · 主动消息计划书

| 项 | 内容 |
|----|------|
| 文档 | 独立分册（主计划见 `2026-09-11-tongpin-lite-plan.md`） |
| 状态 | 设计定稿 |
| 前置 | Lite：私聊 + 朋友圈；无群聊；Bridge 4 并发对话；出图独占显存 |
| 约束 | 本地 Qwen 9B 免费；RTX 4070 12GB；parallel=4 / 总 ctx 65536 |

---

## 1. 目标

角色在 **对话自然结束后** 能「还想说一句」，像真人余韵，而不是系统闹钟刷存在感。

本地模型不计费 → 频率可以高；约束改为：**占槽、抢显存、语气是否假**。

---

## 2. 产品原则

1. **主触发是事件，不是固定周期**：本局聊完 → 空闲 → **+5 分钟** 再考虑开口。  
2. **允许 SILENT**：不是到点必说话。  
3. **多角色可同拍**：最多 **4 槽并行**探活（刚聊完的人优先）。  
4. **不进生图默认路径**：主动默认只出文字；配图/发照片仍走 Scene，且出图时暂停主动。  
5. **一有新消息就取消重计**：避免已经聊上了还弹余韵。  
6. **提示词保持 Lite**：无设备长文、无 Comfy、无 planning JSON。

---

## 3. 范围

### In Scope

- 私聊角色主动短讯（微信体）  
- Idle 判定 + **5 分钟** 余韵延迟  
- 最多 4 角色并行探活  
- 可选：单角色「内心 → 正文」两段式  
- 可选：同拍朋友圈动态（无图或另走 Scene）  
- 长空闲稀疏心跳（补充，低优先）  
- 冷却、每拍/每日上限、出图与打字时抑制  

### Out of Scope

- 群聊主动、群接龙  
- 通知监听、位置、日历、前台 App 等系统感知  
- 完整版 AgentTurnCoordinator / 世界导演  
- 主动默认自动生图（二期可选）  

---

## 4. 状态机

```text
ACTIVE
  用户或角色有新消息
    │
    ▼
IDLE  （最后一条消息后 60–90s 无新消息）
    │  记 idleAt，预约 idleAt+5min
    │
    ├─ 出现新消息 ──────────────► ACTIVE（取消预约，重新计时）
    ├─ 用户开始输入 / 出图开始 ──► HOLD（顺延或取消本拍）
    │
    ▼  +5min 且仍空闲
PROBE_FANOUT （并行探活，最多 4 槽）
    │
    ├─ 全部 SILENT ──► 等待下次事件（可进稀疏心跳）
    ├─ 有正文 ───────► 限流落库 + 通知 ──► 可选再次 Idle 计时
    └─ 出图中 ───────► 整拍取消/顺延
```

### Idle 判定

| 参数 | 建议 | 说明 |
|------|------|------|
| `idleQuietMs` | 60–90 秒 | 最后一条消息后无新消息 |
| `afterglowDelayMs` | **5 分钟**（可配 3–8） | 从 idleAt 起算 |
| 取消条件 | 任意新 user/assistant 消息 | 取消后按新的最后消息重计 |

---

## 5. 并行与 4 槽

### 5.1 候选排序（每拍）

1. **刚 Idle 的线程角色**（权重最高，必进候选）  
2. 其它已开「主动」的角色：仅当 **单角色冷却** 已过  
3. 排序：冷却剩余短、距上次主动久、今日主动少者优先  

每拍并行角色数：`min(4, 候选数)`；**两段式开启时** `min(2, 候选数)`（每角色 2 槽）。

### 5.2 槽位布局

**模式 A — 一角色一槽（默认）**

```text
槽0 刚聊完的角色     探活
槽1 其它角色         探活（可选）
槽2 其它角色         探活（可选）
槽3 其它角色         探活（可选）
```

**模式 B — 两段式（更自然，推荐本地默认开）**

```text
槽0 角色A 内心一句（≤15 字，不发送）
槽1 角色A 依内心+最近聊天 → SILENT 或微信正文
槽2 角色B 探活（可选）
槽3 角色C 探活（可选）
```

### 5.3 抢占与让路

| 条件 | 行为 |
|------|------|
| Bridge `mode=IMAGE` 或 Comfy 队列非空 | **本拍全部不执行** |
| 用户与某角色 ACTIVE | 该角色本拍强制 SILENT |
| LM Studio 槽不足 / 请求排队超时 | 丢弃本拍，不重试堆积 |
| 单角色 in-flight | 跳过该角色 |

主动任务优先级：**低于**用户对话，**远低于**已开始的出图。

### 5.4 落库限流（防刷屏）

即使 4 槽都返回正文：

| 参数 | 建议 |
|------|------|
| 每拍真正写入/通知 | **1–3** 条 |
| 单角色冷却 | 15–25 分钟 |
| 每角色每日主动 | 4–8 条 |
| 全局每日主动 | 15–30 条（本地可上调） |

超出候选：生成可丢弃或只写入不通知（默认丢弃）。

## 6. 提示词（Lite）

### 6.1 探活 / 正文（单段，模式 A）

**System（短，无 Comfy/无设备长文）**

```text
你是「{name}」。
人设（≤400–600）：{personality}
关系（一句）：{relationship}
最近聊天（2–4 条短摘录）：{recent}
现在大约是 {时段}，距上次聊天约 {minutes} 分钟。
你过着自己的生活。有时想找用户，有时不会。
若想说话：只输出要发的那条消息，微信体，自然口语，可带一点当下状态，≤60 字。
若不想：只输出 SILENT
禁止：列表、书面腔、「作为AI」、提系统/模型、问要不要照片、编造用户没说过的事。
```

### 6.2 两段式（模式 B）

**槽0 内心（不落库）**

```text
只输出一行 ≤15 字中文：{name} 此刻在干嘛/心情。不要输出给用户看的完整消息。
```

**槽1 正文**

```text
内心：{inner}
最近：{recent}
输出 SILENT 或一条 ≤60 字微信体给用户。规则同 6.1 禁止项。
```

### 6.3 朋友圈同拍（可选）

与私聊 **另一槽/另一拍**；正文中文短动态；**配图**仍走 Scene tag 流水线，出图前卸 LLM。

### 6.4 输出校验

- 仅 `SILENT` 或非空正文  
- 正文长度上限（如 120 字）  
- 含 markdown/列表/「作为AI」→ 丢弃（可重试 1 次）  
- **不**自动带 `tools` / scene

## 7. 数据与调度

### 7.1 新增（概念）

| 项 | 用途 |
|----|------|
| `character.proactive_enabled` | 是否参与主动 |
| `character.proactive_style` | 一句「何时会主动」（可并入人设末行，可不单独建字段） |
| `thread.lastMessageAt` | Idle 计算 |
| `proactive_pending` | 预约的 +5min 任务 id / fireAt |
| `character.lastProactiveAt` | 冷却 |
| 日计数 | 可内存或轻量存储 |

### 7.2 调度

- Android `WorkManager` 或协程 `delay` + 进程内队列；进程被杀后用 WorkManager 恢复  
- 预约键：`proactive:{threadId}`；新消息 → `cancel + 重约`  
- 每拍：`ProactiveFanout` 协程同时 `async` 最多 4 个 chatStream/chat  

### 7.3 与 Lite 主计划的衔接

- 复用 `LiteSystemPromptBuilder` 思想：短人设；主动再套 §6 模板  
- 不复用完整版 `AgentTurnCoordinator`  
- Bridge：CHAT 态直接并发转发；IMAGE 态 App 侧已抑制  

---

## 8. 模块拆分

| 模块 | 职责 |
|------|------|
| `ProactiveIdleWatcher` | 监听最后消息 → Idle → 预约 +5min / 取消 |
| `ProactiveGate` | 纯规则：时段、冷却、限额、ACTIVE、IMAGE、输入中 |
| `ProactiveLifeProbe` | 单槽探活或两段式 |
| `ProactiveFanout` | 最多 4 并行、收结果、限流落库、通知 |
| `ProactiveNotify` | 本地通知文案（角色名 + 短讯） |

## 9. 参数表（默认）

| 参数 | 默认 | 可调 |
|------|------|------|
| Idle 静默 | 75s | 60–90s |
| 余韵延迟 | **5min** | 3–8min |
| 每拍并行角色 | 4（两段式则 2） | 2–4 |
| 单角色冷却 | 20min | 15–40min |
| 每拍落库上限 | 2 | 1–3 |
| 每日全局上限 | 24 | 12–40 |
| 单条长度 | ≤60 字 | ≤80 |
| 探活重试 | 1 | 0–2 |
| 安静时段 | 可全局 23:30–7:30 关 | 按角色作息二期 |
| 长空闲心跳 | 可选 2h | 默认关或 1–3h |

## 10. 异常与边界

| 场景 | 处理 |
|------|------|
| App 被杀 | WorkManager 恢复 pending；无则不补发陈旧余韵 |
| 模型离线 | 跳过本拍，写诊断日志，不重试刷屏 |
| 连续多次 5min | 单角色冷却兜底 |
| 用户秒回 | 取消预约，不探活 |
| 出图中到点 | 取消；结束后可不补（避免和聊天抢） |
| 多线程同角色 | 同角色全局一把锁 |

---

## 11. 验收

- [ ] 私聊停止后约 5 分钟，可能出现该角色主动短讯  
- [ ] 期间若继续聊天，**不会**再出现旧余韵  
- [ ] 主动文案口语、无系统腔；SILENT 不落库  
- [ ] `/status` 或日志可见 **2–4 路并发** 探活（多角色时）  
- [ ] 生图期间无主动  
- [ ] 冷却与每拍上限生效（不刷屏）  
- [ ] 主动 system 无 Comfy、无设备长文  

---

## 12. 实施顺序

| 步 | 内容 | 验收 |
|----|------|------|
| P0 | IdleWatcher + 单角色 +5min 单槽探活 | 余韵一条 / SILENT |
| P0 | 取消重计 + 出图抑制 + 冷却 | 不抢戏 |
| P1 | Fanout 4 并行 + 落库限流 | 多角色同拍 |
| P1 | 两段式内心→正文 | 语气更自然 |
| P2 | 朋友圈同拍、长空闲心跳、通知文案打磨 | 生活感 |
